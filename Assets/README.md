# Assets folder

Put your final brand images here and keep the same file names so the site
picks them up automatically — no code changes needed.

- `favicon.svg` (or replace with `favicon.png` / `favicon.ico` and update the
  `<link rel="icon">` tag in `index.html` if you change the file type)
  → used as the browser tab icon.
- `logo.svg` (or replace with `logo.png`)
  → used as the logo in the top navigation bar and can be reused in the footer.

Recommended sizes:
- favicon: 512×512 (square), transparent or solid background
- logo: at least 400×400 (square) or a wide horizontal logo (e.g. 600×160)

After replacing the files, just redeploy the site — the current `index.html`
already links to `/assets/favicon.svg` and `/assets/logo.svg`.
